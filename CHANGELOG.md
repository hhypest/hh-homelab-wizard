# История изменений

Здесь описываются фактически внесённые изменения hh-homelab-wizard. Версия мастера независима от версии устанавливаемого hh-homelab. Планируемые функции находятся в [плане разработки](docs/DEVELOPMENT_PLAN.md), а не в списке реализованных возможностей.

## Unreleased

### Added

- Начальное описание визуального установщика на C# / Avalonia / MVVM.
- Зафиксированный объём первого выпуска: Windows/Linux → Synology DSM 7.x / DS725+, новая установка Media и Home Assistant по SSH.
- Требования к первичной настройке медиасервисов, интеграциям HA, сущностям, панели и проверке автоматизаций.
- Детальный план разработки с этапами, зависимостями, критериями приёмки и матрицей испытаний.
- Инструкции для агентов и правила участия в разработке.
- MIT для кода и машинных профилей, CC BY 4.0 для документации.
- Правило Git для текстовых файлов с окончаниями строк LF.
- Начало M0: C#-решение .NET 10, Domain/Infrastructure, ProfileCheck и QbProbe, central package versions и lock-файлы.
- Исследовательский профиль hh-homelab v1.3.0 с 19 fingerprints, девятью сервисами, VueTorrent 2.36.1 и покрытием всех 118 шагов инструкции.
- ADR по архитектуре, журналу/секретам и доставке Monitor Docker; протокол частичных локальных API-проб.
- 36 unit/fixture-проверок профиля и контракта qBittorrent 5.2.4; workflow сборки и тестов Windows/Linux.

### Project status

- Начальная документация подготовлена 10 октября 2026 года.
- Ядро и developer tools собираются; M0 не закрыт. Автоматического установщика, Avalonia UI и пользовательских пакетов пока нет.
- Локальная сборка, unit/fixture-тесты и часть disposable Docker-проб выполнены. UI-тесты и установка на NAS не выполнялись; bootstrap qBittorrent ещё не подтверждён.

### Changed

- Уточнена обязательная клиентская матрица первого выпуска: Windows 10 x64, Windows 11 x64 и Ubuntu 24.04 LTS x64 / X11. Требования к приёмке и испытаниям обновлены; совместимость приложения пока не проверена.

После первого выпуска добавляйте разделы версий с датой, изменениями поведения и значимыми ограничениями. Не переносите будущие этапы в `Added` до их реализации.
