# Текущая готовность

Единственный сводный источник готовности продукта. Обновляется при изменении поведения или принятого результата; история находится в [CHANGELOG](../CHANGELOG.md), доказательства — в протоколах, текущая работа — в [Issues](ISSUE_ROADMAP.md). Числа тестов берутся из отчётов запусков, не поддерживаются вручную в статусах.

Демонстрация не подключается к NAS. Существующие M0-клиенты сохраняют контрактные намерения в памяти; перенос их полного состояния ещё не выполнен. Новый сценарий может использовать локальный файловый журнал: продолжение подтверждено на искусственной операции после принудительной остановки процесса. Это не remote ownership, не готовый resume установщика и не доказательство crash durability при сбое питания. Runtime-пробы не подтверждают DSM ACL или реальные устройства.
