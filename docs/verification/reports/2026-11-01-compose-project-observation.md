# Протокол: read-only наблюдение Compose-проекта

Тип: протокол проверки; результат относится только к указанной базе и среде.

Дата: 01.11.2026. База: `d818f2e8` (`main`, merge PR #131). Частичный #50/#51 для #101, родители #20/#21. Решение: [ADR 0027](../../adr/0027-compose-project-observation.md). Точный head, CI и review фиксируются в PR.

## Среда

Linux x64, .NET SDK 10.0.401, `/bin/sh` — dash. Docker daemon локально не запускался: поведение скрипта проверено под настоящим shell против подставного `docker`, отвечающего из файлов; живой nested Docker — задание `ssh-runtime (docker)` в CI.

Команды: locked restore, Release build, `dotnet test HhHomelab.Wizard.slnx`, DocsCheck.

## Локальные проверки

| Область | Проверено |
| --- | --- |
| Identity | Имя проекта из рендера совпадает с `name:` Compose-файла; верхний регистр, длина, не-hex, кавычки, `{{`, пробел, ведущий дефис, путь вне `/volumeN` отвергаются |
| Оценка | Absent только при прочитанном Docker; своя сеть без контейнера и с контейнером — Owned; любой чужой ресурс — Foreign; контейнер без сети или два своих контейнера — Ambiguous; частичный Unavailable, дубли, усечённые ID, больше 16 совпадений и неизвестное состояние отвергаются |
| Отпечаток | Не зависит от времени и порядка; меняется при смене владения и состояния контейнера |
| Протокол | Запрос — одно значение на строку; parser отвергает чужую версию, отсутствие `end`, неизвестную запись, сеть после контейнера, неизвестные состояние/владение, лишнее поле, записи при Unavailable, короткий ID, хвост после `end` и ненулевой код |
| Probe | Снимок привязан к одобренному ключу; ключ другой конечной точки — InvalidInput без подключения; изменённый ключ — отказ без чтения; неверный ответ — InvalidResponse; дедлайн и отмена вызывающим различаются; параллельный вызов — Busy |
| Скрипт под `/bin/sh` | Отсутствие совпадений — Absent; метки своего проекта — Owned/Running; отличие проекта, сервиса, `oneoff`, каталога или отсутствие меток — Foreign; значение с добавленным `\n`, `\n\n` или пробелом — Foreign; другой ключ сети — Foreign; пустые строки фильтра подстроки пропускаются |
| Отказы скрипта | Сбой `network ls`, `container ls`, `inspect`, неизвестное состояние, короткий ID, 17 совпадений и отсутствие docker дают только `status=unavailable` без записей |
| Только чтение | Подставной docker фиксирует вызовы: только `ls` и `inspect`, все на `unix:///var/run/docker.sock`, `DOCKER_HOST` окружения не используется; неверный запрос завершается кодом 2 до вызова docker |

Итог локального запуска: UnitTests 1339/1339 (65 новых), DesktopTests 18/18, сборка без предупреждений, DocsCheck без замечаний.

## Стенд в CI

`ComposeProjectScenarios` выполняется в `ssh-runtime (docker)` после прежних preflight-сценариев: production probe через настоящий SSH на nested Docker Engine 29.9.2. Фикстура сама создаёт `internal` bridge-сеть и созданный, но не запущенный контейнер импортированного rootfs с метками Compose; Compose не запускается. Сценарий проверяет Absent, Owned с одной сетью, Owned с контейнером Created, отсутствие совпадения по подстроке имени, Foreign для тех же имён под проектом другой установки, неизменность при переменных окружения Docker, Unavailable при закрытом socket и восстановление, затем удаляет только свои ресурсы и сверяет итоговый снимок ресурсов daemon с исходным. Результат конкретного запуска фиксируется в PR.

## Не проверено

Запущенный контейнер на живом daemon (только fixtures), соответствие `config-hash`, настоящий `docker compose up`, DSM/Container Manager и реальный NAS.
