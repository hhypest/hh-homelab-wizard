# Клиентская проверка владельцем

Дата сообщения: 2026-10-18. Проверенная сборка: `e8902bd64171486a90b8f3ce0eb2dc725406da39`, [PR #106](https://github.com/hhypest/hh-homelab-wizard/pull/106). Источник результата — сообщения владельца в текущем задании. Это клиентская проверка пользователем, отдельная от native CI и headless fixtures.

| Среда по сообщению владельца | Подтверждено | Что не уточнено |
| --- | --- | --- |
| Windows | Первичная проверка интерфейса; успех, ошибка, отмена и Unknown без ошибок и замечаний | Версия/build ОС, DPI, способ запуска пакета и наличие .NET |
| Linux / X11 | Те же демонстрационные исходы без ошибок и замечаний | Дистрибутив/версия, desktop, графические зависимости, способ запуска и наличие .NET |
| Linux / Wayland | Те же демонстрационные исходы без ошибок и замечаний | Дистрибутив/версия, compositor, фактический backend процесса, способ запуска и наличие .NET |

В первом сообщении владелец уточнил, что **клавиатура, темы и масштабирование не проверялись**. Отсутствие замечаний в первом прогоне относится к перечисленным демонстрационным исходам. Дополнительное подтверждение ниже относится к другой сборке.

Результат добавлен в [#42](https://github.com/hhypest/hh-homelab-wizard/issues/42), [#43](https://github.com/hhypest/hh-homelab-wizard/issues/43), [#44](https://github.com/hhypest/hh-homelab-wizard/issues/44). Полная матрица и упаковка [#45](https://github.com/hhypest/hh-homelab-wizard/issues/45), включая заявленные Windows 11 x64 / Ubuntu 24.04 LTS x64, остаются открытыми до точных сведений и оставшихся сценариев. Подтверждение не переносится автоматически на другие сборки/версии/сеансы.

Владелец подтвердил: «Проверка интерфейса прошла полностью — клавиатура, масштабирование, темы. На Windows и Linux X11/Wayland». Проверенная сборка: `1a42f4bf3189476176e4b467c017b520a273d418`, merge [PR #108](https://github.com/hhypest/hh-homelab-wizard/pull/108). Ранее указанный `1f232b1…` исправлен владельцем; он не используется как доказательство.

| Среда по уточнению владельца | Результат |
| --- | --- |
| Windows 11 26H1 | Полная проверка интерфейса, клавиатуры, масштабирования и тем без замечаний |
| Ubuntu 24.04.4 LTS / GNOME / X11 | Те же проверки без замечаний |
| Ubuntu 24.04.4 LTS / Wayland, Weston/GNOME | Те же проверки без замечаний; compositor указан владельцем в такой форме |

Принято как пользовательская проверка GUI указанной сборки. Клавиатура, темы и масштабирование больше не числятся непроверенными. Числовые значения DPI и поэлементный checklist в сообщении не перечислены. Полный номер build Windows, версии compositor, фактический native backend, запуск пакета без установленного .NET, состав пакета/графические зависимости и screen reader отдельно не подтверждены. Остаток #42–#45 относится к этим сведениям и упаковке/доступности; повтор пройденных GUI-сценариев только из-за обновления протокола не требуется.
