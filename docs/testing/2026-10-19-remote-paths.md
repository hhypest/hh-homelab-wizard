# Read-only проверка путей

Дата: 2026-10-19. База: ветка PR #115 (`1f47013`, протокол preflight v2). Задачи: [#49](https://github.com/hhypest/hh-homelab-wizard/issues/49), prerequisites [#101](https://github.com/hhypest/hh-homelab-wizard/issues/101). SDK 10.0.401, SSH.NET 2026.0.0, build-time profile hh-homelab 1.3.0; зависимости не изменены. Решение: [ADR 0016](../adr/0016-remote-path-inspection.md).

## Локальные fixtures

- Раскладка: восемь ролей, соответствие `/data/torrents/...` и `/data/media/...`; кириллица и пробелы допустимы; относительные, вне `/volumeN`, `/volume0`, USB, `//`, `.`, `..`, `\`, перевод строки, завершающий `/` и вложенные/совпадающие корни отвергаются; соседний префикс `data-config` не считается вложением.
- Запрос содержит пути только как данные stdin; `$(id)` в пути не попадает в текст команды.
- Свежая раскладка на одном устройстве: проверки путей и hardlink-устройства Passed, permissions Unverified, DSM ACL NotChecked.
- Существующая медиатека разрешена; непустой корень конфигурации блокирует как ownership-required, пустой и отсутствующий — Passed.
- Symlink в пути или предке, файл в пути или предке, недоступный путь, недоступная каноническая форма и отсутствующий том блокируют только затронутую роль; сама точка монтирования может быть существующим предком.
- Разные устройства загрузок и медиатеки или неизвестное устройство блокируют hardlink; корень конфигурации на другом устройстве допустим.
- Неизвестные значения, неверная глубина/содержимое для типа, mode вне восьмеричного 7777, лишние/пропущенные поля, путь вместо числа, лишняя запись, чужой marker, отсутствующий `end`, ненулевой код — весь ответ отвергается. Регрессия: восьмеричный mode `7777` декодируется в 4095 (исправлена граница, ошибочно записанная десятичным `07777`).
- Fingerprint стабилен для одинакового наблюдения и меняется при изменении состояния или раскладки; снимок требует ровно одно наблюдение на роль в порядке раскладки.
- Замечания автоматического ревью PR #116 закрыты регрессиями: путь на устройстве `/` блокируется как `volume-unmounted`; глубина предка для максимального корня и фиксированных подкаталогов допустима; существующий нечитаемый каталог блокируется; снимок и fingerprint различают SSH-пользователя и endpoint; компонент 128 кириллических символов (256 байт) и непарный суррогат отвергаются. Имя файла из перевода строки проверено локально скриптом (`ls -A` с подстановкой давал пустую строку, подсчёт байта — 1) и на стенде.
- SSH-проба: первый/изменённый ключ не отправляет запрос; успешный снимок привязан к ключу и профилю; auth/transport/response, Busy, отмена и deadline дают только типизированный отказ.

Фиксированный скрипт запущен локально (Linux, dash): каталог, отсутствующий путь с глубиной предка, symlink-предок, файл-предок, непустой каталог; ответ принят production-парсером. Под непривилегированным пользователем закрытый родитель дал `unavailable` для всех путей, а не `missing`. Строка `$(touch ...)` в пути осталась литералом. Отсутствие `end` и неверный marker дают код 2.

Локально Linux / SDK 10.0.401: locked restore, Release build без предупреждений и ошибок, все unit/fixture и Desktop тесты, JournalProbe и ProfileCheck прошли. Docker daemon локально недоступен: SshDockerProbe остановился на `bench.docker.info.failed` до создания ресурсов.

## Одноразовый OpenSSH-стенд в CI

В build context добавлена embedded-копия того же `nas-paths.sh`; ForceCommand сравнивает полный текст и исполняет только собственную копию, запрос остаётся на stdin. `/volume1` — отдельный tmpfs-mount контейнера (не bind mount хоста), `/volume3` — оставшийся каталог на корневой файловой системе. Control plane от root создаёт синтетическое дерево (медиатека с файлом, непустая конфигурация, конфигурация с файлом-переводом строки, symlink, каталоги 0700, обычный файл). Проба от пользователя `wizard` проверяет:

1. существующую медиатеку, отсутствующие загрузки с глубиной предка 2, владельца root, absent configuration, одно устройство, NotChecked ACL и стабильный fingerprint повтора;
2. symlink-корень и symlink-предок, непустую конфигурацию, недоступный каталог 0700 как unavailable (и предок, и сам существующий каталог), файл-предок как not-directory, отсутствующий `/volume2`, `/volume3` как volume-unmounted и конфигурацию с именем-переводом строки как ownership-required;
3. пути с `;`, `$(...)` и обратными кавычками остаются литералами, в home/tmp не появляется файл;
4. malformed и deadline без частичного снимка, затем успешное восстановление.

Результат CI, commit и definition hash фиксируются в PR и #49; наличие сценария не объявляется успешным прогоном.

## Не проверено

DS725+/DSM: btrfs subvolumes и `st_dev` общих папок, DSM ACL, PUID/PGID контейнеров, `@eaDir`, реальный hardlink. План и UI (#50), ownership (#51–#53).
