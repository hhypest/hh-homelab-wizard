## Локальные fixtures

План собирается настоящим `QbittorrentPlanCompiler` на синтетических снимках. Граф выполняет настоящий `ConfigurationPlanScenario` с `FileOperationJournal`. NAS — один синтетический корень для путей, маркера и файлов, правила которого совпадают со скриптами.

- Compose: закреплённые образ и mods, `WEBUI_PORT` и публикация с выбранным портом 19080, три монтирования, имя сети из `.env`, хеш источника в шапке; нет `9080` и адресов другого NAS.
- `.env`: ровно девять значений запроса, `MEDIA_ROOT` в одинарных кавычках. Повторная отрисовка даёт те же байты.
- Корень данных с `:` или `'` — `render.data-root.unsupported`.
- Граф: три шага, маркер первым, оба файла зависят от него, три разных ресурса. Повторное построение даёт тот же отпечаток; другой WebUI port — другой.
- План с Blocking (bind на loopback) — `graph.plan.blocking`. План старше двух минут — `graph.plan.stale`. Pin другого endpoint — `graph.pin.mismatch`.
- Выполнение: Applied, одна запись маркера и по одной записи каждого файла; содержимое совпадает с отрисованным, `.env` 600. Повтор новым процессом — AlreadySatisfied без записей.
- Потеря ответа при записи `.env` — Unknown; новый процесс подтверждает наблюдением, записей по-прежнему две.
- Ручное изменение Compose после установки: resume — Conflict, изменённый файл не перезаписан.
- Чужой маркер: Conflict на первом шаге, ни одного файла.
- Собственная проверка диффа (автоматическое ревью Codex недоступно: исчерпан лимит) нашла и закрыла:
  - pin того же endpoint, но с другим ключом — `graph.pin.mismatch`;
  - свежесть отсчитывается от начала preflight: ровно на границе граф строится, через секунду — `graph.plan.stale`;
  - Compose получил собственное имя проекта `hhw-<installation ID>`;
  - корень данных с `:` или `'` — Blocking-проверка плана, граф не строится;
  - профиль с другим хешем источника отвергается renderer;
  - освобождённый граф бросает `ObjectDisposedException`; отрисованные буферы обнуляются после копирования.
- План, заново собранный «новым процессом» после установки (свой маркер, непустой корень), не имеет Blocking и даёт тот же отпечаток графа, хотя отпечаток плана другой.
- Маршрутизатор владения отдаёт проверку владельцу ресурса, чужой ресурс — Foreign; операция без порта владения и дубль ресурса отвергаются.
- Стабильные ID: GUID версии 8, зависят от установки и роли.

Локально Linux / SDK 10.0.401: Release build без предупреждений и ошибок, все unit/fixture и Desktop тесты.

## Каталоги монтирования в графе

Дополнение от 19.10.2026 после слияния PR #124 и #125; база `main` с обоими слияниями. Граф получил шаги `ConfigurationDirectory` для `media/config/qbittorrent` и `media/watch` (режим 750), зависящие от маркера. Синтетический NAS дополнен каталогами по правилам скриптов ADR 0024: существующий каталог не меняется; свой с тем же режимом — `already-present`; потеря ответа наступает после реального создания.

- Граф: пять шагов, маркер первым, два каталога и два файла зависят от него, пять разных ресурсов; отпечаток по-прежнему стабилен между процессами.
- Выполнение: Applied, по одной записи маркера, каждого каталога и каждого файла; каталоги с режимом 750. Повтор новым процессом — AlreadySatisfied без записей.
- `media/watch`, заранее созданный Docker от root (`present:755:other`), — Conflict; каталог не изменён и не пересоздан.
- Потеря ответа при создании `media/config/qbittorrent` — Unknown; новый процесс подтверждает наблюдением без повторного создания.
- Чужой маркер: Conflict на первом шаге, ни каталогов, ни файлов.

Локально Windows 11 / SDK 10.0.401: Release build без предупреждений и ошибок, все unit/fixture и Desktop тесты.
