# ADR 0003: Monitor Docker и состав локального профиля

Статус: принято направление доставки; установка и перезапуск HA ещё не проверены.

Для первого выпуска выбираем прямую доставку закреплённого Monitor Docker без обязательной установки HACS. Источник: tag `1.20`, commit `78abdc40d96871be44bd965202de59fe2e5b10d3`; manifest содержит **1.20b3**, зависимости `aiodocker==0.25.0`, `python-dateutil==2.9.0.post0`. Версию tag нельзя выдавать за значение manifest. Лицензия компонента — Apache-2.0; она не заменяется MIT проекта.

Перед использованием нужны проверенный архив/перечень файлов, контрольные суммы, лицензия, проверка безопасного извлечения, атомарная доставка в custom_components и запуск на HA 2026.10.0. Пока архив в репозитории не распространяется и компонент в стенд не установлен. Если потребуется HACS, это будет явно интерактивная опция с авторизацией GitHub.

Локальный профиль исключает облачные Yandex Smart Home/YandexStation и создание внешних ботов. Пачка с уже предоставленным webhook — опция. У исходного `alice.yaml` есть локальные сенсоры `sensor.server_*`, на которые ссылается панель; удалять весь файл без выделения этих определений нельзя. `monitoring.yaml` вызывает `script.pachca_notify`, а панель содержит кнопки облачного и webhook-отчёта.

Будущий компилятор должен выделить локальные aliases метрик, формировать panel/actions под выбранные функции и удалять зависимые ветви выключенного модуля. Нельзя заменять выключенные действия фиктивными secrets или пустыми сценариями, скрывая зависимость. Полная проверка ссылок, включая динамические шаблоны, обязательна перед отключением плееров.
