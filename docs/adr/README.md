# Архитектурные решения

Тип: реестр документов и статусов.

[Архитектура](../engineering/architecture.md) · [Дорожная карта](../../ROADMAP.md) · [Каталог](../catalog.md)

ADR фиксируют причины решений, альтернативы и границы. Статус ниже кратко повторяет строку «Статус» самого ADR; «инкремент» означает разработку на fixtures или одноразовом стенде по [ADR 0008](0008-audit-development-sequence.md), а не приёмку на настоящем NAS. Текущая готовность — в [ROADMAP](../../ROADMAP.md).
