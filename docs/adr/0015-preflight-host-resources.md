# ADR 0015: модель NAS, слушающие порты и место томов в read-only preflight

- Дата: 2026-10-19.
- Статус: частичный инкремент [#48](https://github.com/hhypest/hh-homelab-wizard/issues/48), design/fixtures и одноразовый стенд по [ADR 0008](0008-audit-development-sequence.md).
- Основа: [первый preflight](0013-read-only-nas-preflight.md), [Docker через SSH](0014-docker-preflight-runtime.md).

## Решение

Фиксированная команда получает версию протокола `nas-preflight:v2`. Помимо прежних сведений она читает:

- модель из `upnpmodelname` в `/etc.defaults/synoinfo.conf` как данные через awk — кандидатный DSM-контракт, как VERSION/INFO в ADR 0013;
- TCP-сокеты в состоянии LISTEN из `/proc/net/tcp` и, если таблица есть, `/proc/net/tcp6` — только номера портов, без адресов, процессов и соединений;
- `df -P -k` только для точек монтирования `/volumeN`: общий и доступный объём. USB, `@docker`, системный раздел и вложенные пути не выводятся.

Ни один параметр не подставляется в команду. Нечитаемая таблица сокетов или неуспешный `df` дают `unavailable`, а не пустой список. Лимиты: 256 портов, 16 томов, 128 контейнеров; превышение, дубликаты, неверный формат, `available` меньше нуля или больше общего объёма отвергают весь снимок. Максимальный допустимый ответ укладывается в общий лимит SSH-вывода 16 KiB, это проверено тестом.

## Требования плана

Порты и необходимый объём не выдумываются из примеров: их передаёт будущий конкретный план #50 через `PreflightRequirements` (до 64 TCP-портов, точка монтирования `/volumeN`, минимальный свободный объём). Без требований `Evaluate` оставляет `preflight.ports` и `preflight.disk-space` в NotChecked, хотя факты собраны.

С требованиями:

- нечитаемые слушатели/тома — Blocking `*.unavailable`;
- слушатель на требуемом порту — Blocking `preflight.ports.conflict`, список даёт `ConflictingPorts`;
- выбранного тома нет — Blocking `preflight.disk-space.volume-missing`, мало места — `preflight.disk-space.insufficient`;
- иначе соответствующая проверка Passed.

Наблюдаемая модель остаётся Unverified, отсутствующая или нечитаемая — Blocking, как версии DSM.

## Границы

Passed для портов означает только отсутствие TCP-слушателя в сетевом namespace SSH-сессии. Он не учитывает UDP, iptables DNAT без userland proxy, слушатели в других namespace и опубликованные порты остановленных контейнеров; последние уже блокируются непустым inventory до ownership. Слушатель на любом адресе считается конфликтом: адрес привязки не различается, это консервативно.

Место тома проверяется на момент наблюдения и не резервируется. Свободный объём естественно меняется, поэтому не входит в environment fingerprint; модель, набор портов, точки монтирования и общий объём входят. Перед Apply нужен новый preflight, как и прежде. Квоты общих папок, ACL и пути внутри тома — #49.

Аппаратного подтверждения DS725+ нет: путь `synoinfo.conf`, наличие `/volume1` и представление docker-proxy в `/proc/net/tcp` проверяются отдельно (#39/#48). Полные #48, M2 и #101 не закрываются.
